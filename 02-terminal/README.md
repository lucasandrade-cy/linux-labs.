
# 02 — Linux Terminal Commands

> Anotações e exemplos dos comandos utilizados no terminal Linux.

## 1. Navegação

| Comando | Função |
|---|---|
| `pwd` | Mostra o diretório atual |
| `ls` | Lista arquivos e diretórios |
| `cd` | Acessa outro diretório |

## 2. Manipulação de arquivos

| Comando | Função |
|---|---|
| `mkdir` | Cria diretórios |
| `touch` | Cria arquivos |
| `cp` | Copia arquivos |
| `mv` | Move ou renomeia arquivos |
| `rm` | Remove arquivos |

## 3. Visualização de conteúdo

| Comando | Função |
|---|---|
| `cat` | Exibe o conteúdo de arquivos |
| `less` | Permite visualizar arquivos por páginas |
| `head` | Exibe as primeiras linhas |
| `tail` | Exibe as últimas linhas |

## 4. Exercício de prática

Experimente os seguintes comandos em um ambiente Linux:

```bash
pwd
ls
mkdir laboratorio
cd laboratorio
touch anotacoes.txt
ls
```

**Objetivo:** criar um diretório, acessá-lo e criar um arquivo de anotações.
