## O que é Linux?

Linux é uma família de sistemas operacionais baseados no kernel Linux. É amplamente utilizado em servidores, computadores, dispositivos embarcados e ambientes de infraestrutura.

## Conceitos estudados

- Kernel: núcleo responsável por gerenciar os recursos do sistema.
- Shell: interface que permite interagir com o sistema por comandos.
- Terminal: ambiente utilizado para executar comandos.
- Distribuição: sistema que combina o kernel Linux com ferramentas e aplicações.
